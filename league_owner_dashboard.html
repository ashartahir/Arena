ℹ️ League Guidelines

What is a League?
A league is a collection of multiple tournaments that run over a period of time. Players compete across all tournaments to earn points and rankings.

Requirements:
• League must have a clear name and description
• Select at least 2 tournaments
• All leagues require admin approval
• Entry fees are optional

Features:
• Create seasonal competitions
• Track player rankings
• Set prize pools
• Manage multiple tournaments
